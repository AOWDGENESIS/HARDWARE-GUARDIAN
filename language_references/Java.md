# Java - Programmierreferenz

PROGRAMMING_LANGUAGE: Java
DOCUMENT_TYPE: Language Reference
STATUS: Consolidated 2026-09-14

## Rolle
Java ist ein etablierter JVM- und Enterprise-Standard und bleibt ausserdem fuer Android-Projekte relevant.

## Engineering-Regeln
- Maven oder Gradle reproduzierbar konfigurieren.
- Exceptions nicht verschlucken.
- Ressourcen mit try-with-resources verwalten.
- Threads und Concurrency bewusst modellieren.
- Eingaben und externe Daten validieren.

## Typische Werkzeuge
- JDK
- Maven
- Gradle
- JUnit
- Java Flight Recorder

## Android-Hinweis
Java ist auf Android weiterhin unterstuetzt. Fuer neue Android-Anwendungen ist Kotlin die primaere moderne Wahl.
