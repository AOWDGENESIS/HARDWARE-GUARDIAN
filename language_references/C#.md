PROGRAMMING_LANGUAGE: C#

## Rolle
C# ist stark im .NET-Umfeld, auf Windows, im Enterprise-Bereich und bei Unity.

## Engineering-Regeln
- Nullable Reference Types aktiv nutzen, wenn das Projekt dies erlaubt.
- Exceptions zielgerichtet behandeln.
- Async/await korrekt verwenden.
- Ressourcen ueber using beziehungsweise IDisposable verwalten.
- Tests mit reproduzierbaren Builds kombinieren.

## Typische Werkzeuge
- .NET SDK
- dotnet CLI
- xUnit oder NUnit
- MSBuild
