# Android - Programmiersprachen und Plattformstack

PROGRAMMING_LANGUAGE: Kotlin (primary), Java (supported), C++ (native via NDK)
DOCUMENT_TYPE: Platform Language Reference
STATUS: Added for Android coverage
DATE: 2026-09-14

## Primaere Sprache
Kotlin ist die primaere moderne Sprache fuer neue Android-Anwendungen.

## Weiterhin relevant
Java bleibt auf Android unterstuetzt und ist fuer bestehende Anwendungen und Bibliotheken wichtig.

## Native Komponenten
C++ kann ueber das Android NDK fuer native, performancekritische oder bestehende C/C++-Komponenten eingesetzt werden.

## Nicht verwechseln
Android ist eine Plattform, keine einzelne Programmiersprache. Ein Android-Projekt kann mehrere Sprachen und Build-Technologien kombinieren.

## Empfohlener Standard
Neue normale Android-App:
Kotlin + Android Studio + Gradle + Android SDK + Jetpack.

Native Spezialkomponente:
Kotlin/Java fuer die App-Schicht und C++ nur dort, wo native Integration einen echten technischen Vorteil bringt.
