PROGRAMMING_LANGUAGE: Go
DOCUMENT_TYPE: Language Reference

## Rolle
Go eignet sich besonders fuer Cloud-Dienste, Infrastruktur, Netzwerkdienste und kompakte Serveranwendungen.

## Engineering-Regeln
- gofmt verbindlich verwenden.
- Fehler explizit behandeln.
- Goroutines kontrolliert beenden.
- Context fuer Abbruch und Timeouts verwenden.
- go test und go vet in Qualitaetsgates aufnehmen.

## Typische Werkzeuge
- go
- gofmt
- go test
- go vet
- staticcheck
