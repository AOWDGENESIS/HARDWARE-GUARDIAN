# Local AI usage

Give the local model both reference files when possible:

1. `reference/KI_Dauerreferenz_Programmierung_und_Softwarequalitaet_DE.md`
2. `reference/LOAD_INSTRUCTION.txt`
3. `runtime/KI_Maschinenprofil.md`

The stable reference is authoritative for engineering behavior. The runtime profile is authoritative only for current environment facts.

Do not treat version numbers, paths, ports, model names or hardware details as permanent rules.
