# Runtime data

This directory is intentionally split from the stable reference.

The updater creates these local files:

- `KI_Maschinenprofil.json`
- `KI_Maschinenprofil.md`
- `logs/KI_Dauerreferenz_AutoUpdate.log`

They are ignored by Git because they can contain machine-specific information such as usernames, paths, installed tools, model names, ports and environment values.

Run the updater locally to refresh them.
