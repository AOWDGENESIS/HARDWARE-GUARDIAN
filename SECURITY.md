# Security Policy

## Reporting

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature when it is available for this repository. Do not publish secrets, personal data, full diagnostic dumps, or exploit details in a public issue.

## Safe use

This software interacts with Windows diagnostics and may include maintenance workflows. Review every proposed change, keep backups, and do not assume a restore point or rollback can succeed in every environment. Do not run untrusted builds with administrator privileges.

When reporting a problem, include the affected version, Windows build, minimal reproduction steps, and redacted logs.
